ギタリストには「歪み系沼」という病気があります。

そもそもギター用エフェクター自体の種類も多いのですが、その中でも「歪み系」と言われるDistortion、Overdrive、Fuzzをついついいくつも集めてしまう病気です。楽曲の中では、歪み具合以外は聞き手にとって大して違わないと重々承知していますが、ちょっとした音の違いが気になって集めてしまうのです。

今回は集めてしまった歪み系エフェクターを科学的に分析して数値で確かめてみることにしました。周波数特性、時間変化、ダイナミクス、倍音、ノイズ、音色の近さを解析しています。

解析のスクリプトと録音データは[GitHubのリポジトリー](https://github.com/yostos/overdrive-pedal-analysis)で公開しています。

## 録音と解析の方法

ギターで4弦7フレットA音を単音で鳴らして減衰させた演奏をDitto 2にループとして録音し、そのループを毎回再生してペダルに通しました。音源はすべてのファイルで同じです。録音の経路は次のとおりです。

1. Ditto 2（ルーパー）
2. Strymon Compadre（オフにして、バッファーだけを通す）
3. 比較するドライブペダル
4. DSM & Humboldt Simplifier MK-II（PreampとPower AmpはMS-Brit、CabinetはStack、Blue）
5. UAFX Orion Tape Echo（Simplifier MK-IIのSend/Returnに接続する。エコーはオフ、プリアンプはオン）

比較したのは次の7機種です。Broadcast AP-IIはGermaniumとSiliconの2モード、Riversideは2つのトグルを切り替えて3通りを録音したので、設定は全部で10通りになります。基準として、ペダルを通さない音（以下、Raw）も録音しました。どのペダルも、つまみは12時で比較しています。

| 正式名 | 本文での表記 | 設定 |
|---|---|---|
| Hudson Electronics Broadcast AP-II | Broadcast Ge | Germanium |
| 同上 | Broadcast Si | Silicon |
| BOSS DS-1W | DS-1W | S-mode |
| MXR Distortion+ | Distortion+ | |
| Vin-Antique PPSE Classic | PPSE Classic | |
| Strymon Riverside | Riverside low | High/LowはLow、Mid Pushはオフ |
| 同上 | Riverside low-mid | High/LowはLow、Mid Pushはオン |
| 同上 | Riverside high | High/LowはHigh、Mid Pushはオフ |
| BOSS SD-1W | SD-1W | S-mode |
| Xotic Soul Driven | Soul Driven | |

ペダルごとに音量が違うため、録音後にLogic Proでピークが同じくらいになるようにゲインを調整しています。また、手動で録音を始めたので、ファイルの冒頭にある無音の長さがまちまちです。そこで音の立ち上がりを検出して時刻を揃え、すべてのファイルを8.336秒の同じ長さで切り出しました。

Rawを含むすべてのファイルには、Simplifier MK-IIとOrionのプリアンプによる色付けが入っています。そのため解析では、値そのものよりもRawとの差を見ています。共通の色付けを差し引いて、ペダルによる違いだけを取り出すためです。

ペダルの性格を表す指標として、次の6つを測りました。本文で示す順位は、Rawを除く10通りの設定を、この表の「順位の付け方」に従って並べたものです。順位は音の優劣でなく、単にその指標の強さを示します。

| 指標 | 測り方 | 順位の付け方 |
|---|---|---|
| サステイン | ピークから-10dBに下がるまでの時間 | 長いほど上位 |
| 圧縮 | 立ち上がりから2秒間のクレストファクタ（ピークとRMSの比。小さいほど圧縮が強い） | 圧縮が強い（クレストファクタが小さい）ほど上位 |
| アタック | 音量が最大値の10%から90%に上がるまでの時間 | なだらかな（時間が長い）ほど上位 |
| 重心 | 立ち上がりから1秒間のスペクトル重心の平均 | 高いほど上位 |
| 高次倍音 | 9〜20次（約2〜4.4kHz）の倍音レベルのRawとの差の平均 | 多いほど上位 |
| ノイズ | 立ち上がり前の区間のノイズフロア（ピークを揃えてあるため、ピークに対するノイズの大きさ） | 大きいほど上位 |

スペクトル重心は、音のエネルギーがどの周波数を中心に分布しているかを表す値で、高いほど明るい音になります。高域が増えた場合だけでなく、低域が減った場合も上がります。

音色の総合的な近さは、MFCC（人の聴覚の特性に合わせて、スペクトルの大まかな形を表す係数）の差を距離として求めました。値が小さいほど似た音で、全組み合わせの最小は12です。ファイル全体の距離に加えて、立ち上がり（0〜0.3秒）、持続部（0.3〜2秒）、減衰部（2〜5秒）に分けた距離も求めています。

ペダルごとの図は4つのグラフからなります。そのペダルを色付きの太線、Rawを黒の破線、ほかのペダルを灰色の細線で表示しているので、全体の中での位置が分かります。

| グラフ | 見るところ |
|---|---|
| スペクトルのRawとの差（左上） | 全体のパワーを揃えたうえでの差。0dBより上はRawより強い帯域、下は弱い帯域 |
| 減衰カーブ（右上） | 線が上にあるほどサステインが長い |
| 倍音ごとのレベルのRawとの差（左下） | ペダルが加えた倍音。差が出るのは主に9次（約2kHz）以上 |
| スペクトル重心の時間変化（右下） | 線が上にあるほど、相対的に高域の割合が大きい |

各ペダルの使いどころについての推察は、測定値から演奏や音作りでの働きを推し量ったもので、実際に聴いて確かめた評価ではありません。

## Strymon Riverside

<!-- textlint-disable -->

{{< image src="riverside-low.webp" alt="Riverside lowの測定結果。スペクトル、減衰カーブ、倍音、スペクトル重心のグラフ" />}}

<!-- textlint-enable -->

RiversideのLowゲインモードは、ダイナミクスがRawとほぼ同じです。サステイン（0.85秒）、圧縮（クレストファクタ20.7dB）、アタック（2.1ms）はいずれも10台の中で最もRawに近く、減衰カーブはRawと重なります。その一方で、音色は変わります。低域の割合がRawの45.7%から31.2%に減り、1–2kHzの割合は19.8%で10台中最大です。Rawとの距離も23で、総合的にも最もRawに近い設定でした。

<!-- textlint-disable -->

{{< image src="riverside-low-mid.webp" alt="Riverside low-midの測定結果。スペクトル、減衰カーブ、倍音、スペクトル重心のグラフ" />}}

<!-- textlint-enable -->

Mid Pushをオンにすると、Lowゲインモードと比べて250–500Hzの割合が26.5%から32.6%に上がり、1–2kHzは19.8%から13.6%に下がります。サステインは0.85秒から1.20秒に、高次倍音は+2.0dBから+9.7dBに増えます。一方、アタックは2.5ms、クレストファクタは17.1dBで、立ち上がりの鋭さと圧縮の弱さはほぼ保たれます。TS系を狙ったスイッチだと思いますが、MFCC距離で最も近いのはPPSE Classic（13）で、全組み合わせの中で2番目に近い値でした。

<!-- textlint-disable -->

{{< image src="riverside-high.webp" alt="Riverside highの測定結果。スペクトル、減衰カーブ、倍音、スペクトル重心のグラフ" />}}

<!-- textlint-enable -->

Highゲインモードでは、Lowゲインモードと比べて帯域のバランスはほとんど変わらず（各帯域の差は3.1ポイント以内）、サステインは1.67秒、高次倍音は+18.4dBと、Mid Pushより大きく増えます。サステイン、圧縮、高次倍音はいずれも10台の4〜5位で、ちょうど中ほどです。500Hz–2kHzが多く、スペクトル重心は3位でした。アタックは3.4msで、同じくらい歪むペダルより鋭さを保っています。

2つのトグルの働きを比べると、Mid Pushは中低域を厚くしつつ歪みを少し足し（250–500Hzが+6.1ポイント、高次倍音が+7.7dB）、High/Lowは帯域のバランスを保ったまま歪みの量を切り替えます（帯域の差は3.1ポイント以内、高次倍音が+16.4dB）。

Riversideは、アナログのJFET入力段の後ろの段で、DSPによって歪みを作っています。[Strymonの解説](https://www.strymon.net/single-stage-multistage-gain-topologies-sunset-riverside/)によると、Driveのつまみに応じて、段と段の間の回路の定数（各段のゲインと周波数特性を決める）を連続的に変えています。そのため、ここで見た設定による変化はStrymonが設計したDSPによるもので、アナログのペダルでゲインのつまみを回したときの変化の参考にはなりません。

Lowゲインモードは、歪ませずにEQで音色を整えるのに近い働きなので、歪ませる用途より、クリーントーンの補正やアンプのキャラクター付けに向くと考えられます。1–2kHzは音の輪郭に関わる帯域とされ、ここが増えることで、バンドの中で音を聞き取りやすくなる可能性があります。

Mid Pushをオンにした音は、中低域が厚く、歪みは軽い〜中程度なので、ピッキングの強弱に追従しやすいクランチと推察されます。PPSE Classicとほぼ同じ役割を担えると考えられます。

Highゲインモードは、中ほどの歪みなので、リフとリードの両方に使える中ゲインと考えられます。アタックが鋭いので、歪ませても速いフレーズの粒が立ちやすいはずです。

2つのトグルを組み合わせれば、1台でクリーントーンの補正から中ゲインまでをカバーできると考えられます。

## Hudson Electronics Broadcast AP-II

<!-- textlint-disable -->

{{< image src="broadcast-ge.webp" alt="Broadcast Geの測定結果。スペクトル、減衰カーブ、倍音、スペクトル重心のグラフ" />}}

<!-- textlint-enable -->

Germaniumモードは、10台の中で最も歪みが少ない設定です。9〜20次倍音の増加は+1.7dBで最小、17次より上はRawより小さくなります。音色のバランスもRawに最も近く、80Hzより下を約12dB削るほかは、100〜500HzがRawとほぼ同じ（平均-1.4dB）です。スペクトル重心もRawとほぼ同じで、減衰していく間の重心の動きもRawと重なります。サステインは1.04秒、クレストファクタは18.0dB（Rawは0.80秒、21.6dB）で、ダイナミクスの変化も小さめです。アタックは6.3msで、Rawより少し丸くなります。立ち上がりの瞬間だけ7〜12kHzの成分が出るのも特徴で、10台の中でこのペダルだけでした。

<!-- textlint-disable -->

{{< image src="broadcast-si.webp" alt="Broadcast Siの測定結果。スペクトル、減衰カーブ、倍音、スペクトル重心のグラフ" />}}

<!-- textlint-enable -->

Siliconモードは、スペクトル重心が10台の中で最も低く、Rawより低くなる唯一の設定です。2–5kHzの割合も4.8%で最小なので、相対的に低域の割合が大きくなります。サステインと圧縮はGeとほぼ同じで、9〜16次の倍音はGeよりおおむね2〜4dB多くなります。偶数次と奇数次の倍音の比（2.8dB）と、倍音と倍音以外の成分の比（25.1dB）は、Rawを含む11ファイルの中でどちらも最大で、倍音以外の成分が相対的に少ない音です。GeとSiの距離は12で、全組み合わせの中で最も近い値でした。主な違いは2–5kHzの割合（Geは7.9%、Siは4.8%）です。

区間ごとの距離を見ると、Broadcastは立ち上がり（0〜0.3秒）の音がほかのペダルと似ていません。Geは、Siを除いて最も近いRiverside low-midでも距離36で、全組み合わせの中央値（43）に近い値です。Siも立ち上がりでは、最も近いペダルとの距離が24で、持続部や減衰部より離れます。一方、持続部と減衰部ではRiverside low-midに近いため、ファイル全体の距離もRiverside low-mid（Geは17、Siは16）と近い値になります。全体で平均すると、時間の長い持続部と減衰部の影響が大きく、短い立ち上がりの違いが薄まるためです。また、低域の割合はGeの48.0%に対して、Riverside low-midは33.6%です。

どちらのモードも、音色を大きく変えずにわずかな歪みとサステインを足す使い方、つまり軽いブーストやほかの歪みペダルの前段に向くと考えられます。圧縮が弱いので、ピッキングの強弱も出音に反映されやすいはずです。GeとSiのどちらを選ぶかは、主に高域の量で決まります。Siは耳に刺さる高域と濁りが少ないので、高域を抑えたいクランチや、クリーン寄りのダークで滑らかなトーンに合います。対して、Geはより明るいトーンになります。今回測定しませんでしたが、この2つはカスケードできるので、この特性付けはよいバランスかもしれません。

ファイル全体の距離だけを見るとRiversideで代用できそうですが、立ち上がりがほかのペダルと似ておらず、低域の割合も大きく違います。低域を保ったまま軽く歪ませる役割は、Riversideでは代わりがききにくいと考えられます。

## Vin-Antique PPSE Classic

<!-- textlint-disable -->

{{< image src="ppse-classic.webp" alt="PPSE Classicの測定結果。スペクトル、減衰カーブ、倍音、スペクトル重心のグラフ" />}}

<!-- textlint-enable -->

PPSE Classicは、低域を最も削り、中低域から中域を持ち上げるペダルです。低域の割合は26.9%で10台中最小、150Hz付近は約-20dBと全ペダルで最も深く削れています。逆に250–500Hzの割合は34.7%で最大です。9〜16次の倍音は+10〜22dB増えますが、18次（約4kHz）より上はRawと同じくらいに戻ります。アタックは2.9msで、中程度に歪ませてもRawに近い鋭さを保ちます。ピークに対するノイズは-70.3dBFSで、10台の中で最も小さい値でした。

ベースとぶつかりにくく、ギターの帯域で前に出る音なので、バンドの中でのリズムギターに向く可能性があります。アタックが鋭く圧縮は中程度なので、ピッキングの強弱で歪みの量を操作しやすく、高次の倍音が4kHzより上で増えないことから、歪ませても耳に刺さる成分が増えにくいと考えられます。ノイズが小さいので、録音やダイナミクスの大きい曲でも扱いやすいはずです。

ただし、Riverside low-midとの距離は13で、全組み合わせの中で2番目に近い値でした。区間ごとに見ても、立ち上がり、持続部、減衰部のどこでも近く（15、13、13）、帯域のバランス、倍音の増え方、サステインがほぼ同じです。違いは150Hz付近の削り方（PPSE Classicは約-20dB、Riverside low-midは約-10dB）くらいで、どちらか一方で代用できる可能性があります。

## BOSS SD-1W

<!-- textlint-disable -->

{{< image src="sd-1w.webp" alt="SD-1Wの測定結果。スペクトル、減衰カーブ、倍音、スペクトル重心のグラフ" />}}

<!-- textlint-enable -->

SD-1Wは、中域（500Hz–1kHz）の割合が21.3%で10台中最大です。低域を減らし、150Hz付近を約17dB削っており、ミッドを持ち上げるTS系に近い傾向を示しています。アタックは13.5msと、Soul Drivenに次いでなだらかです。減衰しても重心が下がりにくく、2秒以降の重心はPPSE Classicと並んで全ペダルで最も高くなります。偶数次と奇数次の倍音の比は0.9dBで、11ファイルの中で最小、相対的に奇数次の倍音が多い音です。

[TS系（TS-808、OD-1、SD-1）の回路の解説](https://electricdruid.net/?p=66938)によると、SD-1はダイオードをオペアンプの帰還回路に入れたソフトクリップの回路です。クリップの前にある約720Hzの低域カットは固定で、ゲインのつまみには連動しません。720Hzより下はほとんど増幅されないので、クリップもしにくくなります。ゲインを上げると中域が低域より相対的に強まり、帰還回路のコンデンサで決まる高域の上限は下がります。低域を削って中域が多いという特徴（150Hz付近が約-17dB、500Hz–1kHzの割合が21.3%）は、ゲインを変えても残ると考えられます。

中域が前に出るので、バンドの中で埋もれにくく、リードに向くと考えられます。重心が下がりにくいことから、ロングトーンでも埋もれにくいはずです。低域を削る特性は、歪ませたアンプの前に置いたとき、低域の膨らみを抑えて輪郭を保つ使い方にも合う可能性があります。立ち上がりが丸いのでピッキングの硬さが和らぐ一方、速いフレーズでは音の粒立ちが弱くなるかもしれません。

奇数次の倍音が多い歪みは、一般に硬く、ざらついたエッジのある音に聞こえるとされます。偶数次の倍音が多い歪みの、柔らかく温かい音とは対照的です。SD-1Wは、ピッキングの瞬間は丸く立ち上がりながら、伸ばした音にはほかのペダルより硬めの歪みの質感が乗ると推察されます。

## MXR Distortion+

<!-- textlint-disable -->

{{< image src="distortion-plus.webp" alt="Distortion+の測定結果。スペクトル、減衰カーブ、倍音、スペクトル重心のグラフ" />}}

<!-- textlint-enable -->

Distortion+は、低域の割合が56.0%で10台中最大、250–500Hzが15.2%で最小です。中低域を削った、低域と高域が目立つ音で、高次の倍音はDS-1WやSD-1Wと同じくらい多くなります。サステインは2.08秒で3位と長い一方、クレストファクタは16.5dBで6位にとどまり、アタックのピークを比較的残しています。歪みの量はSD-1Wとほぼ同じ（サステインは2.08秒と2.06秒、高次倍音は+23.0dBと+23.5dB）なのに、クレストファクタはSD-1Wの12.9dBより3.6dB大きい値です。ゲインの高い4台（DS-1W、Distortion+、SD-1W、Soul Driven）の中では、Rawとの距離が39で最も近い値でした。

[ElectroSmashの回路解析](https://electrosmash.mas-effects.com/mxr-distortion-plus-analysis)によると、Distortion+はオペアンプ1段のあと、ダイオードでグラウンドへクリップするハードクリップの回路で、トーンのつまみはありません。ゲインのつまみは、オペアンプ段の低域カットも決めています。ゲイン最大では約720Hzから下を削り、ゲインを下げるほど削り始める周波数が下がります。12時で低域の割合が最も多いのは、低域カットがまだ低い周波数にあるためと考えられます。ゲインを上げれば、歪み、サステイン、圧縮が増え、低域カットの周波数も上がります。ただし深くクリップさせると、削られた低域も十分に増幅されてクリップするため、単音の持続部では効きにくく、効くのはクリップしなくなる減衰の後半や、低音弦を弾いたときです。同じくらい歪むSD-1Wより圧縮が弱いという測定結果も、12時での特徴ということになります。ゲインのつまみで変わらない帯域の特徴は、回路からは見当たりません。

いわゆるドンシャリ寄りの音なので、単体では迫力が出やすい反面、バンドの中ではベースと低域がぶつかったり、ギターの帯域が埋もれたりする可能性があります。音を長く伸ばしながらもピッキングの粒立ちが残るので、リードで表情を付けやすいと推察されます。高ゲインの中では、原音の傾向を残した歪みと言えそうです。

## BOSS DS-1W

<!-- textlint-disable -->

{{< image src="ds-1w.webp" alt="DS-1Wの測定結果。スペクトル、減衰カーブ、倍音、スペクトル重心のグラフ" />}}

<!-- textlint-enable -->

DS-1Wは、スペクトル重心が10台の中で最も高く、圧縮も最も強いペダルです。2–5kHzの割合は15.6%でRawの約2倍あり、4.9kHz付近を最大17.5dB持ち上げています。250–500Hzは18.3%と少なく、中低域を抑えて高域を強調する音です。ただし重心が高いのは立ち上がり直後に限られます。直後の重心は約1.8kHzで全ペダルの中で最も高いものの、2秒以降はRawやBroadcastと同じくらいまで下がります。

[ElectroSmashの回路解析](https://electrosmash.mas-effects.com/boss-ds1-analysis)はオリジナルのDS-1のもので、S-modeが同じ回路の値かどうかは確認していません。それによると、DS-1はトランジスタ段とオペアンプ段のあと、ダイオードでグラウンドへクリップするハードクリップの回路で、その後ろに固定のトーン回路があります。ゲインのつまみはオペアンプ段の低域カットにも関わりますが、動くのは約72Hz以下に限られます。トーン回路はクリップの後ろにあるので、ゲインには連動しません。ゲインを上げれば歪みと圧縮が増え、倍音が増える分、2–5kHzはさらに多くなります。2–5kHzの割合が最も多いという特徴は、ハードクリップとクリップ後のトーン回路によるもので、ゲインを変えても残ると考えられます。

圧縮が1位、高次倍音の増加が2位なので、歪みを前面に出すハイゲインのリフやパワーコードに向くと考えられます。高域が多く中低域は少ないので、バンドの中では抜けやすい一方、単体では細い音に聞こえる可能性があります。立ち上がり直後だけ重心が高いことから、ピッキングの瞬間が強調され、伸ばした音は落ち着いて聞こえると推察されます。ピークに対するノイズが-59.1dBFSと2番目に大きいので、録音や静かなパートではノイズゲートの併用を検討する価値があります。

## Xotic Soul Driven

<!-- textlint-disable -->

{{< image src="soul-driven.webp" alt="Soul Drivenの測定結果。スペクトル、減衰カーブ、倍音、スペクトル重心のグラフ" />}}

<!-- textlint-enable -->

Soul Drivenは、10台の中で最も歪みが強いペダルです。サステイン（2.65秒）、高次倍音（+29.9dB）、アタックのなだらかさ（15.2ms）がいずれも1位で、圧縮は2位でした。250–500Hzを減らし、500Hz以上を持ち上げています。110Hz付近がRawより約3.5dB強いのも特徴で、ほかのペダルはこの帯域がRawより0〜9dB弱くなっています。110Hz付近の成分は、弾いていない5弦（開放のA）の共鳴として元の音に含まれており、すべてのファイルに入っています。Soul Drivenは、これを相対的に強く通しています。ピークに対するノイズは-55.1dBFSで最も大きく、2位のDS-1Wより4dB大きい値でした。

音色の距離では、ほかのどのペダルとも似ていません。最も近いDistortion+でも距離35あり、Rawとの距離（61）も最大です。

[Aion FXが実機から起こした回路図と解説](https://aionfx.com/news/tracing-journal-xotic-soul-driven-boost-overdrive/)によると、Soul Drivenは3段構成です。1段目はTS系のソフトクリップ段で、MIDBOOSTのつまみが、クリップ前の低域カットの周波数（約135〜884Hz）とゲインを変えます。ゲインを上げるほど、高域の上限は下がります。2段目は受動の高域カット（TREBLE）で、ここから後ろは[BOSS BD-2](https://www.premierguitar.com/articles/boss-bd-2-mods-1)とほぼ同じです。3段目はBD-2と同じ低域ブーストで、約120Hzに共振を作り、その付近を持ち上げます。持ち上げる量は[DIPスイッチ](https://www.xotic.us/effects/soul-driven)で4段階に選べ、デフォルトの「Flat」でもゼロにはなりません。Aion FXは、最小の設定でもBD-2より持ち上げる量が大きいとしています。

この回路は、測定結果とよく対応します。立ち上がりの区間の距離がSD-1Wと最も近い（22.8）のは、どちらもTS系のソフトクリップ段を持つためと考えられます。低域の割合がSD-1Wより多いこと（43.3%と34.7%）と、110Hz付近がRawより強いことは、クリップ後の120Hz付近の持ち上げと、SD-1Wの720Hz固定より低くなりうる低域カットで説明できます。ゲインを上げると歪み、圧縮、サステインが増え、高域の上限は下がりますが、クリップ前の低域カットとクリップ後の120Hz付近の持ち上げは変わりません。そのため、ほかのペダルのゲインを上げれば、サステインや圧縮はSoul Drivenに近づきますが、帯域は同じにならないと考えられます。120Hz付近を持ち上げる回路を持つペダルは、ほかにないためです。

サステインと高次倍音が1位なので、ハイゲインのリードやロングトーンに向くと考えられます。アタックが最もなだらかで圧縮も強いので、ピッキングの強弱が出音に出にくく、なめらかにつながるレガートと相性がよい一方、カッティングのように歯切れが必要な演奏には向きにくい可能性があります。110Hz付近（開放の5弦の共鳴）を強く通し、ノイズも大きいので、弾いていない弦のミュートやノイズゲートなどの対策が、ほかのペダルより重要になりそうです。

## ペダルどうしの近さはどう分かれるか

<!-- textlint-disable -->

{{< image src="clustering.webp" alt="MFCC距離による樹形図（左）と2次元の配置図（右）" />}}

<!-- textlint-enable -->

MFCC距離をもとに、ペダルどうしの近さを樹形図（左）と2次元の配置図（右）で表しました。配置図では、近くにあるペダルほど音が似ています。

配置図は、11ファイルどうしの距離を平面に写したもので、距離の違いの約9割（第1軸72%、第2軸17%）を再現しています。残りの約1割は図に表れないため、本当の距離より近く見える組み合わせもあります。たとえばBroadcast GeとSiは、距離12に対して、図の上では約3しか離れていません。

配置図の軸は、特定の測定値を表すものではありません。そこで、各ファイルの座標と測定値の相関から軸の意味を読みました。横軸（第1軸）は歪みの量に当たり、左ほどサステインが長く（相関-0.83）、1秒間の平均重心が高くなります（-0.79）。縦軸（第2軸）は圧縮の弱さに当たり、上ほどクレストファクタが大きくなります（0.84）。圧縮のほとんどないRawとRiverside lowが上に離れ、下には500Hz–1kHzの割合が大きいSD-1W、Riverside high、PPSE Classicが集まります。相関は11ファイルから求めたもので、目安の値です。

- 大きく2つのグループに分かれる。低〜中ゲインのBroadcast Ge / Si、PPSE Classic、Riverside（3設定）、Rawと、高ゲインのDS-1W、Distortion+、SD-1W、Soul Drivenである
- 特に近い組み合わせは、Broadcast GeとSi（距離12）、PPSE ClassicとRiverside low-mid（13）である
- Broadcastは配置図ではRiverside low-midの近くにあるが、立ち上がりだけを比べると、ほかのペダルから離れる
- Soul Drivenは、どのペダルからも離れている

## どのペダルを残すか

ここまでの測定結果と、公開されている回路の解析をもとに、残すペダルの優先度を付けました。Broadcast（Ge / Si）とRiverside（3設定）は、それぞれ1台として扱います。基準は「ほかのペダルで、つまみの調整を含めても代わりがきかない音を持つものほど残す」とし、次の3点で判断しました。

1. 独自性：自分以外のペダルで最も近いものとのMFCC距離。立ち上がりの区間の距離も見る
2. 代わりのききにくさ：その特徴を、ほかのペダルがつまみの調整で作れるか。ゲインのつまみで変わる特徴は、ほかのペダルのゲインを変えれば近づけられるため、重く見ない
3. カバー範囲：1台で複数の役割を担えるか

サステイン、圧縮、高次倍音の量は、クリップが深くなれば増えるので、どのペダルでもゲインに連動します。一方、帯域の割合がゲインでどう変わるかは、回路によって違います。各ペダルの節で見た回路の特徴をまとめると、次のようになります。

| ペダル | ゲインのつまみで変わらない特徴 | ゲインのつまみで変わる特徴 |
|---|---|---|
| DS-1W | クリップ後の固定のトーン回路による帯域の形 | 歪み、圧縮。倍音が増える分、2–5kHzはさらに多くなる。つまみで動く低域カットは72Hz以下だけ |
| Distortion+ | なし（トーン回路がない） | 歪み、圧縮。低域カットの周波数（ゲイン最大で約720Hz） |
| SD-1W | クリップ前の低域カット（約720Hz固定） | 歪み、圧縮。高域の上限（ゲインを上げるほど下がる） |
| Soul Driven | クリップ前の低域カット（MIDBOOSTで決まる）、クリップ後の120Hz付近の持ち上げ（DIPスイッチで決まる） | 歪み、圧縮。高域の上限（ゲインを上げるほど下がる） |

Riversideは設定による変化をDSPで作っているので、アナログのペダルに当てはめることはできません。BroadcastとPPSE Classicの回路は調べていません。

| 順位 | ペダル | 理由 |
|---:|---|---|
| 1 | Strymon Riverside | 1台でクリーントーンの補正（low）、軽いクランチ（low-mid）、中ゲイン（high）を担う。帯域の割合（Mid Push）と歪みの量（High/Low）を別々に切り替えられる。PPSE Classicの代わりにもなる |
| 2 | Xotic Soul Driven | MFCC距離で最も孤立している。クリップ後に120Hz付近を持ち上げる回路はほかのペダルになく、ゲインでは作れない。10台の中で最も歪ませられる（サステイン、高次倍音、アタックのなだらかさが1位） |
| 3 | BOSS DS-1W | 2–5kHzの割合が15.6%で10台中最大。ほかの9台はすべて10%以下。ハードクリップとクリップ後の固定のトーン回路によるもので、ほかのペダルでは作れない |
| 4 | Hudson Electronics Broadcast AP-II | ファイル全体ではRiverside low-midに近いが、立ち上がりの音色はほかのペダルと似ていない。低域を保ったまま軽く歪ませる役割もほかにない |
| 5 | MXR Distortion+ | ゲインのつまみで変わらない帯域の特徴はない。ただし12時の音（サステインが長いのに圧縮が弱く、低域の割合が56.0%で最大）は、ほかのペダルのつまみでは作れない。TS系（SD-1W、Soul Driven）は低域を削り、DS-1Wは圧縮が強い（クレストファクタ12.5dBと16.5dB） |
| 6 | BOSS SD-1W | Soul Drivenで代わりがきく。同じTS系のクリップ段を持ち（立ち上がりの距離22.8）、Soul DrivenはMIDBOOSTで低域カットをSD-1Wの約720Hz付近（最大約884Hz）まで上げられる。中域の持ち上げはRiverside highにもある |
| 7 | Vin-Antique PPSE Classic | Riverside low-midとほぼ同じ音。違いは150Hz付近の削り方くらい |

Riversideはカバー範囲が広く一番汎用的です。lowはRawに最も近いクリーントーンの補正、low-midは軽いクランチ、highは10台の中ほどの中ゲインと、3つの設定で低〜中ゲインの範囲を受け持ちます。2つのトグルのうち、Mid Pushは帯域の割合を、High/Lowは歪みの量を変えるので、音色と歪みの量を別々に選べます。さらに、low-midはPPSE Classicと距離13でほぼ同じ音なので、PPSE Classicの役割も兼ねられます。

Distortion+とDS-1WはMFCC距離が21と近いものの、12時では反対の性質を持っています。Distortion+は低域の割合が56.0%で最も大きく、同じくらい歪むSD-1Wより圧縮が弱いペダルです。DS-1Wは2–5kHzの割合が15.6%で最も大きく、低域寄りのDistortion+とは反対に高域寄りの音です。MFCC距離はスペクトルの大まかな形を比べる指標で、音量を表す0次を除いているため、圧縮の違いを直接には測っていません。距離は近くても、12時での音の性質は大きく違います。

Broadcastは、ファイル全体の距離だけで見るとRiverside low-midに近く、優先度が低く見えます。しかし立ち上がりの区間ではほかのペダルと似ておらず、低域を保ったまま軽く歪ませる役割もほかにないため、4位としました。

SD-1WをSoul Drivenで代える場合でも、Soul Drivenのクリップ後の120Hz付近の持ち上げは残ります。DIPスイッチの最小の設定でもゼロにならないので、低域を削ったSD-1Wの音と完全には同じになりません。

この順位には、試聴の印象とノイズの大きさを含めていません。ノイズで見ると、Soul Drivenはピークに対するノイズが最も大きいペダルです。

Kitty〜東芝EMI時代の高中正義さんの曲をよくやるので、順位では2位のSoul Drivenは外し、Riverside、DS-1W、Broadcast、Distortion+の4台を常用することにしました。サステインはコンプレッサーで得ているので、Soul Drivenは必要ありません。5位のDistortion+は、Kitty時代の高中さんの歪みがDistortion+なので、音の好みから入れました。

## 分析を終えて

今回の分析で、ペダルどうしの違いや、ほかのペダルで代わりがきくかどうかは、数値で見えるようになりました。歪みの量では、Soul Driven、DS-1W、SD-1W、Distortion+の4台がサステインと高次倍音の上位を占め、Broadcastの2モードとRiverside lowはRaw寄りに並びます。音色では、PPSE ClassicとRiverside low-midのようにほぼ同じ音の組み合わせもあれば、Soul Drivenのようにどのペダルとも似ていないものもあります。

Strymon Riversideはカバーできる範囲が広いので、ペダル間で「大して変わりない」という結果が出て、もっとペダルを整理できるかと期待していました。しかし、少なくとも手持ちのペダルに関しては、それぞれちゃんと個性があり、使う理由もありそうです。

感覚的に感じていた違いが分析でも証明できたので、整理には至りませんでしたが、個人的には大変スッキリしました。
