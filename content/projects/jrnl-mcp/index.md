![jrnl-mcp](cover.webp)

An MCP server for the command-line journal tool
[jrnl](https://jrnl.sh/).
Search entries, view statistics, and analyze
tags directly from Claude Desktop or
Claude Code.

Built as an experiment in connecting
everyday CLI tools with AI.
The read-only design keeps your
private journal data safe.

## Install

```bash
npm install -g jrnl-mcp
```
